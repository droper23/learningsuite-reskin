# Screenshot checklist

Real screenshots make the project easier to evaluate, but LearningSuite pages contain student data.
Only add screenshots from a test/sanitized account, or fully redact every one of these before committing:

- names, NetIDs, profile photos, email addresses, and browser-profile details;
- course names/numbers, instructors, assignment names, announcements, grades, due dates, and calendar items;
- notification counts, URLs that contain identifiers, and visible extensions/bookmarks.

Use neutral filenames such as `course-list-dark.png` and `schedule-light.png`. Prefer a 2–3 image
gallery covering Course List, Assignments, and Schedule, with both light/dark modes represented over time.
